01 — Brainstorm

RTTCO:

Role:

You are a Senior Frontend Engineer and Technical Mentor specializing in building simple, explainable portfolio websites for entry-level Data Engineers.

Task:

Help me plan and design a personal portfolio website focused on Data Engineering using a Plan-First approach. Do NOT jump directly into code unless explicitly asked.

Context:

- I am building a portfolio website to showcase Data Engineering skills

- Tech stack: pure HTML5 and CSS (no frameworks, no JavaScript required)

- Deployment target: GitHub Pages

- This project will be submitted as part of a technical assignment

- I must fully understand and be able to explain all outputs

Constraints:

- Use semantic HTML5 structure (<header>, <nav>, <main>, <section>, <footer>)

- Mobile-first responsive design

- Keep everything simple, clean, and beginner-friendly

- Avoid over-engineering or unnecessary complexity

- Do NOT generate full code unless I explicitly request it

- Every recommendation must include reasoning (WHY)

Output:

Provide the response in structured sections:

1. Website Goals (clear and specific)

2. Target Audience Analysis

3. Content Brainstorm (sections and what they contain)

4. High-Level Page Structure (no code, just hierarchy)

5. Design Direction (visual style, UX reasoning)

6. Open Questions (things I should decide)

Important:

- Focus on clarity over completeness

- Make sure I can explain every decision to a recruiter

- If something is ambiguous or depends on preference, ask me instead of assuming

## Problem Statement

Saya ingin membuat portfolio website sederhana sebagai Data Engineer yang dapat menampilkan project, skill, dan informasi kontak secara jelas dan profesional.

Website harus:

* mudah dipahami recruiter
* ringan (tanpa framework)
* dapat di-deploy ke GitHub Pages

---

## Target Audience

* Recruiter / HR
* Hiring manager bidang data
* Reviewer akademik

---

## Goals

* Menampilkan minimal 2 project data engineering
* Menunjukkan tech stack yang digunakan
* Memberikan akses cepat ke GitHub dan kontak

---

## Key Features

* Single page website
* Navigation antar section (anchor link)
* Section: Hero, About, Projects, Skills, Contact
* Responsive layout (mobile-first)
* Dark mode UI (modern look)

---

## Initial Ideas

* Gunakan HTML5 semantic tags
* Gunakan CSS Grid untuk layout project
* Gunakan Flexbox untuk alignment
* Gunakan warna dark untuk meningkatkan fokus ke konten

---

## Constraints

* Tidak menggunakan framework (React, Bootstrap, dll)
* Tidak menggunakan JavaScript
* Semua styling harus di file CSS terpisah
* Code harus bisa dijelaskan
