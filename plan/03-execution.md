# 03 — Execution

## Workflow Approach

Menggunakan pendekatan Plan-First + RTCC-O dengan bantuan Kiro untuk menghasilkan struktur awal, kemudian dilakukan refinement manual.

---

## Step-by-Step Implementation

### 1. Setup Project Structure

* Membuat folder:

  * index.html
  * style.css
  * assets/
  * plan/

---

### 2. Generate Initial Code (Kiro)

* Menggunakan "Run Required Tasks"
* Menghasilkan HTML dan CSS dasar

---

### 3. Manual Refinement (Penting)

* Menghapus placeholder
* Menyesuaikan data project pribadi
* Menyederhanakan class CSS
* Memastikan semua section sesuai design

---

### 4. Styling Improvement

* Mengubah ke dark mode
* Menambahkan hover effect pada project card
* Memperbaiki spacing dan typography

---

### 5. Content Injection

* Menambahkan:

  * Project ETL E-Commerce
  * Project Air Quality Pipeline
* Menambahkan link GitHub asli

---

### 6. Testing

* Test responsive (mobile & desktop)
* Test navigation anchor
* Test visual consistency

---

### 7. Preparation for Deployment

* Menambahkan folder assets
* Menyiapkan screenshot untuk dokumentasi

---

## Challenges

* Output awal AI terlalu generic
* Perlu refinement agar sesuai kebutuhan
* Menjaga agar tetap simple tapi terlihat profesional

---

## Solution

* Tidak menggunakan output AI secara langsung
* Review dan modifikasi setiap bagian
* Fokus pada code yang bisa dijelaskan
