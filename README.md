# 💻 Data Engineer Portfolio — Web Project

## 📌 About This Project

This project is part of **IT Bootcamp – KAreerr Elevation Vol. 2! 💻**.

The objective of this assignment is to build a **personal portfolio website** using a **Plan-First approach** and structured AI collaboration (RTCC-O framework), while ensuring that all generated output is fully understood and explainable.

Although this is a web development task, the content of this portfolio is intentionally designed to represent a **Data Engineer profile**, making it usable as a real portfolio website.

## 🎯 Project Goals

* Build a **single-page portfolio website**
* Apply **semantic HTML5 structure**
* Implement **responsive design (mobile-first)**
* Use **pure CSS (no framework, no JavaScript)**
* Ensure **all code can be explained clearly**

---

## 🧠 Approach

This project follows:

### 1. Plan-First Development

All implementation is based on predefined documentation:

* Brainstorm
* Detailed design
* Execution plan
* Final results

### 2. RTCC-O Framework

| Component   | Description                               |
| ----------- | ----------------------------------------- |
| Role        | AI as assistant for structured generation |
| Task        | Build portfolio website                   |
| Context     | HTML, CSS, GitHub Pages                   |
| Constraints | No framework, no JS, must be explainable  |
| Output      | Clean, semantic, responsive website       |
